 # Customer Churn Prediction — Machine Learning Project
 
# 📌 Overview

This project builds an end‑to‑end machine learning pipeline to predict customer churn using Python.
It covers data preprocessing, exploratory data analysis (EDA), feature engineering, model training, evaluation, and a deployable prediction script.
The project is tailored for UAE industries such as telecom, banking, insurance, and subscription services where churn prediction is essential for improving customer retention.
# 📂 Project Structure

├── main.py                 # Runs the prediction pipeline
├── app.py                  # Optional API/UI script
├── data/
│   ├── raw/                # Original dataset + EDA notebook
│   └── processed/          # Cleaned and transformed data
├── models/
│   └── churn_model.pkl     # Trained ML model
├── src/
│   ├── data_preprocessing.py
│   ├── model_training.py
│   ├── model_evaluation.py
│   └── __init__.py
├── outputs/                # Charts, plots, and reports
└── README.md



# 🧠 Features

- Data cleaning and preprocessing
- Exploratory data analysis (EDA)
- Feature engineering
- Model training (Logistic Regression, Random Forest, etc.)
- Evaluation using Accuracy, Precision, Recall, F1‑Score, ROC‑AUC
- Saved model for deployment
- Modular, production‑ready Python code
